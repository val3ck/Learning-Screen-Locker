# VIBECODED

## Recall Learning Suite

Локальний навчальний потік для Windows. SQL Recall відкриває практику з PostgreSQL, English Daily і нічний Node.js. Поруч є повні тренажери для SQL і Node.js та окремий English-сайт для допрацювання матеріалу.

| Папка | Що тут |
| --- | --- |
| `recall/` | Windows-застосунок Recall на Electron |
| `SQL/` | Postgres Path і синхронізація SQL-прогресу |
| `english/` | English-сайт для повторення після Recall |
| `nodejs/` | Backend Path, уроки та практика для нічної сесії |
| `shared/` | Читання локальної конфігурації |

## Запуск

Потрібен Node.js 24. З кореня репозиторію запускай `SQL-Recall.bat`. Перший запуск встановить залежності з lockfile і збере застосунки разом із Windows-версією Recall. Для розробки використовуй `npm run setup` і `npm start`. Для перевірки із тимчасовими даними є `npm run demo`.

Окремо можна запустити `npm run start:sql` на порту 4173, `npm run start:english` на порту 5500 і `npm run start:node` на порту 5174. Усі сервери слухають лише loopback. На ПК зі старою копією Recall закрий її через трей перед переходом на нову папку. Якщо старий локальний сервер ще займає потрібний порт, закрий його перед запуском сервера з нового шляху. Адреси й порти збережено для наявних браузерних даних.

`npm test` перевіряє всі чотири проєкти. `npm run package:win` збирає `recall/release/win-unpacked/SQL Recall.exe`. Для інтеграції з курсами запускай його через кореневий `SQL-Recall.bat` і зберігай структуру папок.

## Локальний реліз Windows

Після змін у Recall запусти з кореня репозиторію **npm run release:win**. Команда збирає окремий Windows-пакет, проганяє перевірки розкладу, прогресу й навчальних модулів та запускає короткий smoke-тест із тимчасовими даними.

Після успіху наступний запуск через **SQL-Recall.bat** або автозапуск Windows вибере готовий пакет. Якщо збірка чи перевірка впала, лаунчер використовує попередній реліз. Резервні збірки зберігаються в підпапках Recall із префіксом **release-local-**.

## Ключі й прогрес

Скопіюй `.env.example` у `.env` у корені, заповни потрібні рядки й перезапусти відповідний застосунок. Підтримуються OpenAI, Groq, Gemini та OpenRouter. `NODE_OPENAI_API_KEY` задає окремий ключ для Node.js. Ключі із зовнішнього середовища мають пріоритет над `.env`. Порожні значення залишають доступними налаштування, збережені локально в Recall або на сайті.

Реальні ключі, локальні конфіги, залежності та збірки виключені через `.gitignore`. У Git зберігається лише порожній `.env.example`.

Recall і прогрес SQL використовують `%LOCALAPPDATA%\SQL Recall\statistics`. English-сайт зберігає допрацювання у `%LOCALAPPDATA%\English Daily\review`, а Backend Path — у `%LOCALAPPDATA%\Backend Path`. Звичайний запуск з тієї самої обліковки Windows підхоплює ці каталоги. Для офлайн перевірки граматики можна додати наявні каталоги `jre` і `languagetool` у `recall/resources/english-checker/`. Ці залежності опціональні та не входять до Git.
