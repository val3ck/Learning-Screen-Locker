# Neovim Quest

Інтерактивна гра українською: 9 розділів, 31 місія, пісочниця та довідник. Браузерний симулятор базових команд Neovim, без залежностей і встановлення редактора.

## Запуск

На Windows двічі натисни `start-localhost.bat` (або `Start-Neovim-Quest.bat` у батьківській папці). Скрипт відкриє браузер після запуску сервера. Потрібен уже встановлений Node.js; npm-пакети не встановлюються. Якщо порт 4173 зайнятий, сервер спробує наступні десять портів. Закрий вікно або натисни Ctrl+C, щоб зупинити його.

Відкрий `dist/index.html` через будь-який статичний HTTP-сервер. Якщо вже є Node.js, виконай `npm start` та відкрий http://127.0.0.1:4173. Встановлення npm-пакетів не потрібне. Модулі ES потребують HTTP; відкриття через file:// не підтримується.

`npm test` перевіряє редактор і проходження всіх місій.

## Можливості

- 9 розділів: рухи; введення; збереження та вихід; слова; видалення та undo; оператори; регістр і Visual; пошук та заміна; фінальний конфіг.
- Перші 5 секунд — порожній екран. Потім питання оповідача, плавна поява консолі та тексту, перша ціль. Повторити вступ можна в меню.
- Короткі діалоги зверху з анімацією друку, вказівник на координати клітинок та автоматичні плавні переходи між завданнями. Enter дозволяє перейти далі одразу після успіху.
- Перша гра пропонує три випадкові цілі в різних частинах поля. Розділи продовжуються тільки після завершення всіх їхніх завдань.
- Англійська за замовчуванням, UKR / ENG у меню перемикає репліки, історію, назви етапів і мануал. Вибір мови зберігається.
- Після кожного з 9 розділів є 3 окремі практичні іспити (27 загалом): чеклісти, повторення нових навичок і збереження незавершеної практики. Новий розділ не починається, поки не пройдено всі три іспити; через меню можна вибрати будь-яку вправу вручну. Після завершення розділу чи іспиту Enter продовжує навчання у твоєму темпі.
- Із четвертого розділу — кодові задачі на JavaScript, Python, Go, C, C++ або Rust. Потрібно реалізувати `solve(n)`; запускний код додається автоматично. Вбудовані тести завжди залишаються; власні випадки додаються у `tests.json` як масив `[{"input":4,"expected":10}]`. F5 запускає перевірку. Клік на вкладку файла або `:e tests.json` / `:e main.js` перемикає буфер зі збереженням чернеток.
- JavaScript виконується в одноразовому worker усередині iframe з непрозорим origin, без мережі та доступу до сторінки, з обмеженням часу. Python, Go, C, C++ і Rust надсилаються у публічний Wandbox API без публікації permalink (`save:false`); для них потрібен інтернет. Недоступність сервісу або помилка компіляції показуються в панелі й не зараховують тест як пройдений.
- Музика за замовчуванням — 0%, діалоги — 50%. Попередній прогрес зберігається; одноразово оновлюються початкові рівні звуку для цієї версії.
- Власний процедурний саундтрек: повільні теплі акорди й рідкі дзвіночні ноти. Короткі синтезовані бліпи супроводжують друк діалогів. Немає сторонніх аудіозаписів чи запозиченої музики.
- Звук активується першим кліком або клавішею; початкові 5 секунд залишаються тихими. У меню є загальне вимкнення та окремі регулятори діалогів і фону. Під час реплік фон стихає, а при втраті фокуса стає на паузу. Налаштування зберігаються в браузері.
- Непомітне бургер-меню справа (також F2): етапи, мануал із пошуком, збережена історія діалогів, натяки, перезапуск і пісочниця. Esc закриває меню.
- Інтерфейс для комп’ютера, керування фізичною клавіатурою; повний екран через Fullscreen API доступний із меню. Анімація враховує prefers-reduced-motion.
- Локальний сервер синхронізує прогрес і чернетки між Recall та звичним браузером. Щоб перенести попереднє браузерне збереження, один раз відкрий гру у звичному браузері з оновленим сервером. На статичному хостингу діє локальне збереження браузера.

## Межі симуляції

Це не вбудований Neovim. Підтримано навчені команди та кілька додаткових основних команд, перелічених у довіднику. Немає файлової системи, плагінів, вкладок, повного набору Ex-команд чи всіх особливостей Vim. `:w` зберігає стан навчального буфера в пам’яті, `:q` закриває тільки симульований буфер. Пошук буквальний; регулярні вирази у замінах використовують синтаксис JavaScript. Складні послідовності dot-repeat та undo можуть відрізнятися від Neovim.

Вебшрифти Google Fonts необов’язкові — є системні резервні шрифти. Гра після завантаження працює без зовнішніх API.
