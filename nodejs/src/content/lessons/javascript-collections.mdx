## Значення та посилання

Копіювання примітива створює незалежне значення. Копіювання змінної з об’єктом дає ще одне посилання на той самий об’єкт. Тому зміна вкладеного поля через одне посилання видима через інше. Оператор spread копіює лише один рівень структури.

~~~js
const original = { user: { name: 'Іра' }, active: true };
const copy = { ...original };
copy.active = false;
copy.user.name = 'Оля';
console.log(original.active);    // true
console.log(original.user.name); // Оля
~~~

Перший запис змінює окреме верхньорівневе поле копії. Другий проходить через спільне посилання на вкладеного user. Для незалежної зміни потрібна копія саме того шляху, який змінюєш. structuredClone підтримує багато типів даних, але теж має обмеження; функції ним не клонуються.

## Операції над колекціями

map перетворює кожний елемент на новий результат. filter відбирає елементи. find повертає перший збіг або undefined. reduce накопичує стан. Звичайний цикл часто простіший, якщо треба кілька підсумків і перевірок одночасно.

~~~js
const orders = [
  { customer: 'a', amountCents: 200 },
  { customer: 'b', amountCents: 450 },
  { customer: 'a', amountCents: 100 }
];
const expensive = orders.filter(order => order.amountCents >= 200);
const amounts = expensive.map(order => order.amountCents);
console.log(amounts); // [200, 450]
~~~

Методи не гарантують повної незмінності. map створює новий масив, але callback може змінити вхідні об’єкти. sort змінює масив на місці; toSorted повертає окремий. Для чисел вкажи числовий comparator, інакше порядок буде лексикографічним.

## Групування

Map зручний для таблиці підсумків: ключі не перетинаються з іменами властивостей прототипу, а get/set явно описують доступ. У лабораторній накопичуй підсумок на клієнта й загальну суму за один прохід. Вхідна колекція залишається власністю викликача.

Перевір порожній масив, повторного клієнта, нульову суму та неправильний запис. Перш ніж додати значення, переконайся, що воно належить контракту. Чітка помилка краща за NaN, який поширюється на всі подальші підсумки й приховує джерело проблеми.
