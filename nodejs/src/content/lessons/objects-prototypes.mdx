## Як знаходиться метод

Коли JavaScript читає object.method, він спочатку шукає власну властивість об’єкта. Якщо її немає, пошук переходить до прототипу й далі ланцюжком до null. Прототип — звичайний об’єкт, пов’язаний з іншим об’єктом. Це механізм делегування, а не копіювання всіх методів у кожний екземпляр.

~~~js
class Counter {
  #value = 0;
  increment() { this.#value += 1; }
  get value() { return this.#value; }
}
const a = new Counter();
const b = new Counter();
console.log(a.increment === b.increment); // true
a.increment();
console.log(a.value, b.value); // 1 0
~~~

Метод increment розташований на Counter.prototype і спільний для екземплярів. Приватне поле #value належить кожному екземпляру. Клас додає зручний синтаксис, але не скасовує прототипної моделі. Водночас його приватні поля та правила виклику конструктора мають власну визначену семантику.

## Інкапсуляція захищає правило

Сенс приватного стану — зберігати інваріант. Для залишку товару це невід’ємне ціле число. Якщо зовнішній код може довільно присвоїти його, перевірка в sell не гарантує коректності всієї моделі.

Методи мають перевіряти новий стан перед зміною. Якщо продаж неможливий, об’єкт залишається в попередньому стані. Це простий принцип атомарності всередині синхронної операції; він ще не забезпечує транзакційність між процесами чи базами даних.

~~~js
const snapshot = [{ sku: 'book', quantity: 3 }];
const detached = snapshot.map(row => ({ ...row }));
detached[0].quantity = 999;
console.log(snapshot[0].quantity); // 3
~~~

Повернення внутрішньої Map напряму зруйнувало б захист. Публічний snapshot має містити нові записи. Самі значення тут примітивні, тому копіювання одного рівня достатнє.

## Успадкування та відповідальність

extends дозволяє делегувати поведінку батьківському прототипу. Використовуй його, коли підтип справді можна підставити замість базового контракту. Якщо потрібно лише поєднати незалежні можливості, композиція часто робить залежності яснішими.

У вправі клас Inventory відповідальний тільки за залишки. Виведення в консоль, збереження у файл та HTTP-статуси залишаються зовні. Так поведінку можна перевірити без мережі та інфраструктури.
