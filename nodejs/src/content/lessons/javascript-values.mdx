## Значення має тип

Примітиви JavaScript — undefined, null, boolean, number, bigint, string і symbol. Об’єкти становлять окрему категорію; масиви та функції теж пов’язані з об’єктною моделлю. Змінна зберігає значення, а const забороняє переприсвоєння змінної. Це не робить вміст об’єкта незмінним.

typeof корисний для початкової перевірки, проте має історичну особливість: typeof null повертає object. Масив перевіряють Array.isArray, а наявність поля — окремо від його значення. Відсутнє поле і поле зі значенням undefined інколи потребують різної поведінки.

~~~js
const raw = '';
console.log(Number(raw));          // 0
console.log(Boolean('false'));     // true
console.log(null == undefined);    // true
console.log(null === undefined);   // false
console.log(Number.isNaN(NaN));    // true
~~~

Пройди кожний рядок: яке саме перетворення відбулося? Непорожній рядок є truthy незалежно від змісту. Number перетворює порожній рядок на нуль. Нестрога рівність може додатково перетворити операнди. Для бізнес-перевірок зазвичай потрібні явна нормалізація та строга рівність.

## Відсутність не дорівнює хибності

Оператор || обирає правий операнд для будь-якого falsy-значення. Оператор ?? робить це лише для null або undefined. Наприклад, допустима кількість 0 загубиться в quantity || 1. Водночас заміна на ?? не скасовує валідації: якщо null заборонений контрактом, його треба відхилити.

~~~js
const quantity = 0;
console.log(quantity || 1); // 1
console.log(quantity ?? 1); // 0
~~~

## Межа системи

Query-параметр, JSON і змінна середовища — зовнішні дані. Перш ніж викликати Number, визнач, які форми дозволено. Чи приймаємо пробіли? Порожній рядок? Десятковий запис? Чи означає відсутність значення застосування default?

У лабораторній контракт навмисно вузький: ціле число від 1 до 100 або рядок лише з цифр; тільки undefined означає default. Спочатку перевір форму, потім перетвори, нарешті перевір діапазон. Такий порядок дає зрозумілі помилки й захищає від випадкових правил приведення типів.

Не використовуй JSON-перетворення як універсальну перевірку значень. Воно має власні обмеження для undefined, bigint та спеціальних чисел, які не відповідають контракту функції.
