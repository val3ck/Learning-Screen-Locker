## Схема захищає правила для всіх клієнтів

API може перевіряти email перед записом, але в базу пишуть також міграції, фонові завдання й адміністративні скрипти. Обмеження PostgreSQL тримають важливі інваріанти в одному місці. Вони працюють і тоді, коли два запити одночасно намагаються створити той самий запис.

```sql
CREATE TABLE customers (
  id integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  email text NOT NULL UNIQUE,
  name text NOT NULL
);

CREATE TABLE orders (
  id integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  customer_id integer NOT NULL REFERENCES customers(id) ON DELETE RESTRICT,
  total_cents integer NOT NULL CHECK (total_cents >= 0),
  created_at timestamptz NOT NULL DEFAULT now()
);
```

Первинний ключ ідентифікує рядок. Зовнішній ключ гарантує, що посилання веде на наявного клієнта. `NOT NULL` забороняє відсутність значення, `UNIQUE` — дубль email, `CHECK` — від’ємну суму. Політика `RESTRICT` не дозволяє непомітно видалити клієнта з його замовленнями.

Унікальність має бізнес-нюанси. PostgreSQL порівнює email за правилами обраного типу й collation; цей приклад не визначає політику регістру чи нормалізації адрес. Її потрібно погодити окремо та послідовно виконувати в застосунку й індексі.

## Модель відображає залежності

Один клієнт має багато замовлень, тому ключ клієнта живе в orders. Для товарів у замовленні знадобиться таблиця рядків: вона збереже кількість і ціну на момент покупки. Поточна ціна товару не повинна змінювати історичний чек.

Схема розвивається міграціями. Початкова міграція створює таблиці в чистій базі; наступні мають враховувати існуючі дані. Додавання `NOT NULL` у заповнену таблицю потребує продуманої послідовності заповнення й перевірки значень.

Автотести лабораторної використовують PGlite — PostgreSQL у WASM. Вони виконують справжні SQL-обмеження без встановлення сервера. Це зручно для моделювання, але багатоклієнтні блокування та мережевий pool досліджуються окремо в Docker PostgreSQL. Перевір кожне обмеження навмисно неправильним INSERT і поясни, який інваріант воно захищає.
