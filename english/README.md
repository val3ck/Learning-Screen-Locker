# English · допрацювання після Recall

Основне навчання залишається в Recall. Цей сайт допомагає закріпити повторювані помилки за короткий підхід на 10, 20 або 30 хвилин. Типово — 20 хвилин. Завершити можна будь-коли; це орієнтир обсягу, а не блокувальний таймер.

Запуск: **start.bat**, або **start_edge.bat** для Edge. Потрібен Node.js 22+. Локальна адреса — http://localhost:5500. Мережа потрібна лише для явного AI-запиту або хмарного озвучення. Шрифти й матеріали локальні.

## Чотири розділи

- **Допрацювання:** конкретні правила, які повторюються в різних відповідях Recall. Поодинокі випадки відкриваються окремо.
- **Бібліотека:** короткі правила, конструкції, теми всіх 84 уроків і матеріали попередніх вкладок. Перші пояснення видимі; решта відкривається за бажанням.
- **Слова й картки:** пригадування без показаного наперед слова, приклади та озвучення. Додатковий словник не відкриває теми Recall автоматично.
- **Мій прогрес:** самостійні застосування, підтверджені труднощі та історія всіх спроб.

Після другої невдачі пропонується правило; після третьої доступний простіший крок; після п’ятої — пропуск із розбором. Однакове повторне надсилання не додає спроб. Помилки API теж не додають спроб. Нову правильну відповідь із підказкою не позначаємо самостійним засвоєнням.

Пріоритет навички знижується після трьох незалежних правильних застосувань щонайменше у два навчальні дні. Повторення ідентичної відповіді в тому самому контексті не створює новий успіх. Пізніша помилка повертає потребу в закріпленні. Частота відображає лише зафіксовані різні відповіді, а не вигадану загальну кількість усіх можливих помилок.

## Дані й незалежність

Власний стан сайту: **%LOCALAPPDATA%\English Daily\review\state.json** та резерв **state.json.bak**. Збережені результати Recall читаються через шлях у recall-config.json; його English-стан, оцінки, SQL-історія й денні бюджети не змінюються. Recall не повинен перезаписувати сайт із маркером .english-review-site.json; для цього встановлюється лише патч сумісності його інсталятора.

Кнопка експорту зберігає історію й поточне допрацювання без API-ключів. Старі браузерні позначки й власні слова імпортуються один раз без видалення оригінального localStorage. Позначка «вивчено» старого сайту зберігається як попереднє знайомство, а не перевірене знання. Старі аудіозаписи й повні відповіді залишаються в початковому сховищі Recall; сайт працює з копіями спостережень.

AI settings використовують уже налаштоване приватне сховище провайдерів. Ключі не повертаються у сторінку. Нові відповіді й кеш практики зберігаються окремо від Recall. Відсутність AI не заважає локальним граматичним вправам, карткам і бібліотеці. CEFR показується лише як орієнтовна оцінка достатнього власного тексту; картки такого бала не отримують.

Виділення → ПКМ → переклад спочатку використовує локальний словник. Наявний особистий словник переноситься копією. AI-переклад запитується окремо в дозволеному режимі, без платного резервного маршруту. Локальний лічильник акційної квоти не бачить використання інших програм.

## Перевірки

```powershell
npm.cmd run test:review
npm.cmd run test:ui
```

Тести UI працюють на ізольованій статистиці. Звичайні тести мережевих моделей не викликають.
