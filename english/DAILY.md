# English Daily

> **Recall 1.5:** English інтегровано до спільної Windows-програми. Основний запуск — [SQL-Recall.bat](../../PGM/winlocker/SQL-Recall.bat). English щодня о 19:00 за Києвом, 55 активних хвилин і до 5 хв перерви; після 23:00 — лише добровільна пропозиція. «Здатись» — після 15 хв. Дані синхронізуються з %LOCALAPPDATA%/SQL Recall/statistics/modules/english, активний урок редагує одне вікно. Браузерний таймер залишається орієнтиром; захищений годинний режим діє в Recall. [Інструкція інтеграції](../../PGM/winlocker/docs/english.md).

12 тижнів, 84 послідовні уроки, приблизно 55 хвилин щодня. П’ять днів нових концептів, один день симуляції й один день закріплення на тиждень. Початковий рівень мови A2–B1, поступове ускладнення до задач B2. Проходження курсу не є сертифікацією рівня.

## Запуск

Потрібен Node.js 22 або новіший. Запусти `start.bat`, `start_edge.bat` або `npm start` і відкрий http://localhost:5500. Зберігай той самий браузер і адресу: localhost, 127.0.0.1 та file:// мають окремі браузерні сховища. Якщо попередній прогрес був на file://, відкрий там index.html, експортуй його й імпортуй на localhost.

Без Node можна відкрити index.html для готових уроків; AI потребує Node-сервера. Мікрофон потребує дозволу браузера. Listening використовує встановлені англійські голоси системи; вони не завжди доступні офлайн. При проблемі є явний перехід до читання транскрипту, який не зараховується як доказ listening.

## AI та ключі

У спільних налаштуваннях Recall доступний також **OpenAI**. Обери його, введи ключ локально, залиш `gpt-6-luna` або вибери доступну акаунту модель через «List available models», постав OpenAI першим у «Text provider order» та збережи. Підтримуються перевірка відповідей, навчальні висновки й підказки через Responses API; ключ не повертається в інтерфейс і не входить до експорту прогресу. Старі налаштування трьох провайдерів зберігають порядок; OpenAI додається наприкінці й без ключа не викликається.

Для Luna перевірки використовують low reasoning, короткі підказки — none та менший ліміт output. Транскрипція й озвучення продовжують використовувати Groq/Gemini та їхні кеші: Luna сама не генерує аудіо. Бюджетні оцінки для 84 уроків — у [COST_ESTIMATE.md](COST_ESTIMATE.md). Реальна плата залежить від витрачених токенів та тарифів акаунта.

Автоматичне переключення ввімкнене за замовчуванням. При ліміті, вичерпаній квоті чи збої використовується наступний API із збереженим ключем у «Text provider order». Повідомлення показує причину, початкову й резервну модель; воно залишається в розборі. Для кешованих оцінок попереднє переключення позначається як збережений результат і не спричиняє нового запиту. Після паузи або `Retry-After` застосунок знову пробує основний API, не змінюючи налаштований порядок. Сам по собі HTTP 429 не оголошується порожнім балансом. Якщо резервів немає, відповіді зберігаються й показується помилка. Переключення можна вимкнути в налаштуваннях; резервний провайдер має власні тарифи й квоти.

**Змішаний режим:** vocabulary, review та reading перевіряє `gpt-5.4-mini`; speaking, writing, додаткову практику, симуляції й тижневі перевірки — `gpt-6-luna`. Обидві моделі можна змінити в налаштуваннях. Режим ставить OpenAI першим і потребує його ключа та підтвердження, що відповідний проєкт уже підключений до акційної програми. Сам застосунок не змінює налаштування передавання даних. Тести з готовими відповідями залишаються локальними.

Для змішаного режиму локальний лічильник резервує input + максимальний output перед запитом, а після відповіді враховує фактичні `input_tokens + output_tokens` (reasoning уже входить в output). Типові денні обмеження — 2 млн для групи mini й 200 тис. для основної групи; скидання о 00:00 UTC. При невідомому usage зберігається консервативна оцінка. Лічильник не бачить інші застосунки й не підтверджує залишок акційної квоти акаунта. Перевищення квоти OpenAI може оплачуватися, тому абсолютної гарантії безкоштовності він не дає. [Офіційні умови](https://help.openai.com/en/articles/10306912-sharing-feedback-evaluation-and-fine-tuning-data-and-api-inputs-and-outputs-with-openai).

У «AI та голос» обери провайдера, введи **новий** ключ, перевір доступні моделі й збережи. Groq використовується для транскрипції (`whisper-large-v3-turbo`), діалогів і перевірки; Gemini — альтернативний провайдер текстового розбору. Початкова текстова модель Groq — `openai/gpt-oss-20b`; модель можна обрати зі списку, доступного акаунту. Транскрипція через Groq працює і коли текстовим провайдером обрано Gemini, якщо Groq-ключ також налаштовано.

Ключі залишаються в `.english-daily-private.json` на локальному Node-сервері. Файл і тимчасовий файл виключені з Git та недоступні через HTTP. Старий браузерний Gemini-ключ видаляється; він не переноситься автоматично. Альтернатива для запуску сервера — змінні середовища `GROQ_API_KEY` і `GEMINI_API_KEY`; вони знову застосуються після перезапуску, доки залишаються встановленими.

Запис відправляється після завершення репліки, якщо підключений Groq. Текст надсилається при запиті розбору чи запитання AI. Без ключа, мережі або квоти доступні готові запитання, приклад відповіді та самоперевірка. Вичерпання квоти не змушує повторювати урок. Застосунок не вмикає білінг і не змінює тариф; квоти й можливі витрати визначає акаунт провайдера.

## Навчання та збереження

У поточному English-модулі Recall завдання повторення містить конкретну дію, підписану підказку та обсяг відповіді. Посилання на попередню роботу відкриває її умову, текст і збережену відповідь поруч. Дублікати повторень об’єднуються; додаткові чернетки залишаються в архіві цього уроку.

Оцінка кожної відкритої відповіді стоїть справа від неї (на вузькому екрані — одразу під нею). Виправлення розкриваються через «Explanation & corrections». Для переходу кожна відповідь має бути за темою, отримати щонайменше 50/100 та 3/4 за виконання завдання. Середній бал блоку сам по собі не відкриває перехід і не визначає рівень англійської.

Перевірки кешуються окремо для кожної відповіді: незмінений текст повторно не надсилається. Зміна умови, пов’язаного контексту, моделі або правил оцінювання потребує нової перевірки. Попередній розбір залишається видимим під час редагування, але його результат не зараховується для зміненої відповіді. Однакові запити допомоги та транскрипції також кешуються. Питання про місце джерела або значення конкретної умови обробляються локально, коли їх можна визначити однозначно.

Listening повторно використовує збережене аудіо. Початкове відтворення — 0.85×; можна обрати 0.75× або 1×. Швидкість зберігається на пристрої й змінюється без нової генерації аудіо.

Після нової AI-перевірки біля відповіді з’являється короткий навчальний висновок: одна головна складність, правило українською, інший англійський приклад і маленька вправа з окремою самоперевіркою. Блок збирає щонайбільше два пріоритети. На них створюються нові вправи в черзі наступного навчального дня; поточні завдання не перебудовуються. Попередні висновки передаються наступному розбору як навчальний контекст і не змушують повторно оцінювати незмінені відповіді.

У «Промпт для іншого ШІ та повторення на наступний раз» можна скопіювати умови, власні відповіді, розбір і висновки. Ключі та налаштування провайдерів не експортуються. Відповідь іншого ШІ у вказаному JSON-форматі імпортується як 1–6 окремих вправ; некоректний імпорт не змінює прогрес. Надсилання в зовнішній чат виконує сам користувач.

Speaking оцінюється як розмова: звичайні паузи, самовиправлення, повтори й пунктуація ASR не прирівнюються до помилок письмового есе. Справжні мовні помилки й пропущені пункти завдання пояснюються окремо. Перед записом є конкретна ситуація та короткий план. Введений текст позначається як письмова альтернатива. Writing також показує ситуацію, адресата, призначення повідомлення й три потрібні пункти. Старі чернетки з власною ситуацією залишаються допустимими.

- Повторення: до 8 елементів / 8 хв, інтервали 1, 3, 7, 14 і 30 днів. Помилки мають пріоритет. Рання змішана практика не переносить дату успішного повторення.
- Допомога й повторна правильна відповідь після помилки позначаються окремо від самостійного пригадування. Відкриті відповіді без AI — самоперевірка, не автоматична оцінка.
- Для початкової діагностики і за відсутності прострочених елементів пропонуються відкриті питання або змішана практика.
- Після завершення додається 100 XP. Наступний обов’язковий урок відкривається наступного місцевого дня. Непройдений урок можна продовжити в будь-який день. Після 84 уроків доступна підтримувальна практика.
- Таймер зупиняється на паузі, у прихованій/неактивній вкладці, під час AI-запитів і після 5 хв без взаємодії. Він не блокує перехід до наступного блоку. 55 хв — план навантаження; реальний час залежить від темпу учня.
- Текст і прогрес — `english_daily_v1` у localStorage. Незавершений урок містить знімок матеріалів, тому перезапуск не змінює завдання. Аудіозаписи — окремо в IndexedDB; після перезапуску доступне прослуховування. У JSON-експорт входять тексти й результати, але не аудіофайли або ключі.
- Імпорт перевіряє структуру, відновлює прогрес бібліотеки й перед заміною завантажує резервний JSON поточного стану. Експорт включає актуальні старі слова/XP/етапи; старі слова не прирівнюються до перевіреного засвоєння.

## Інтерфейс для майбутнього winlocker

`js/daily/examples.js`, `js/daily/course.js` і `js/daily/engine.js` не залежать від DOM. Вони доступні як CommonJS-модулі; у браузері завантажуються в цьому порядку та надають `EnglishExamples`, `EnglishCourse` і `EnglishDailyEngine`. Типи — `js/daily/contracts.d.ts`.

```js
const {Engine} = require('./js/daily/engine');
// adapter implements synchronous getItem(key) / setItem(key, JSON)
const engine = new Engine(adapter);
const session = engine.start(); // resumes existing, or starts next eligible lesson
engine.setAnswer('monologue', 'We use this to…', 'typed');
engine.pause(true);
engine.save();
```

Host рендерить `session.lesson.blocks`, повідомляє активний час через `tick`, зберігає відповіді й результати, перевіряє `requirements`, викликає `advance`, `pause` та `finish`. `finish` перевіряє всі блоки та ідемпотентно прибирає активну сесію. Не потрібно підганяти урок під три SQL-вправи. Recall 1.5 використовує цей рушій через окремий контролер уроку; браузерний та desktop-прогрес синхронізуються.

Локальний AI-інтерфейс: `GET /api/ai/settings`, `POST /api/ai/models`, `POST /api/ai/settings`, `POST /api/ai/transcribe`, `POST /api/ai/dialogue`, `POST /api/ai/evaluate`. Ключ повертається тільки у вигляді прапорця наявності. `evaluate` повертає дві поправки максимум і показники конкретної відповіді 0–4; вимова завжди не оцінена за текстом.

## Перевірки

`npm test` — програма, весь цикл, прогрес, міграція, повторення, календар, імпорт, HTTP-ізоляція й підставні AI-відповіді. Реальні ключі не потрібні. `npm install` і `npm run test:ui` — ізольований headless Edge: повне проходження, відновлення, відсутність API, симуляція, checkpoint і мобільний екран. Для іншого встановленого браузера можна задати `BROWSER_CHANNEL=chrome`. Знімки — у `artifacts/`.

Автоматичні UI-тести підставляють озвучення; вони перевіряють сценарій й переходи, а не якість голосу або фактичні 55 хвилин навчання. Якість реального розпізнавання, доступність безкоштовної квоти й особистий темп перевіряються після підключення нового ключа та першого живого проходження.
