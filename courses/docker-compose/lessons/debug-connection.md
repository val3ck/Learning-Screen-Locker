Продовжуй у тій самій папці з `compose.yaml`. Якщо зупиняв стек, виконай `docker compose up -d`.

## Відтвори й виправ помилку

У формі Adminer спробуй увійти з сервером `localhost`. Потім повтори з `db`. Усередині контейнера `localhost` вказує на сам контейнер Adminer. Ім’я `db` веде до іншого сервісу в мережі Compose.

## Знайди причину з термінала

```sh
docker compose ps
docker compose logs --tail 30 db
```

- `ps` показує стан контейнерів і опубліковані порти.
- `logs` показує, що повідомив процес під час запуску та роботи.
- `healthcheck` описує тест готовності. `depends_on` із `condition: service_healthy` чекає успішної перевірки перед запуском Adminer.

Якщо `up` скаржиться на зайнятий порт `8080`, зміни середнє число в рядку ports на `8081`, запусти `up -d` ще раз і відкрий відповідний порт браузером. Порт у контейнері лишається `8080`.
