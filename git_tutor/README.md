# Git Tutor

Локальний Git-тренажер на 20 основних і 2 добровільні вправи. Кожна вправа має власний навчальний репозиторій. У терміналі працює встановлений Git, а перевірка читає фактичний стан файлів, індексу й комітів.

## Запуск

Відкрий **Start-Git-Tutor.bat**. Потрібні Git for Windows і Node.js 20 або новіший. Якщо браузер не відкрився, скористайся адресою, яку вивів скрипт. Сервер зупиняється через **Ctrl+C** у вікні запуску. npm-пакети та підключення до інтернету не потрібні.

## Клавіатура

- **Enter** виконує команду, **↑ / ↓** відкривають її історію.
- **Ctrl+S** зберігає файл. Файл також зберігається перед виконанням Git-команди та переходом до іншої вправи.
- **F2** відкриває список вправ і довідник, **Esc** закриває меню.
- Для **git add -p** вводь **y**, **n**, **q**, **a**, **d**, **s** або **?** у тому самому полі.

Почни з першої вправи або обери потрібну в меню. Якщо застряг, відкривай підказки по одній. Переставляти вправи й повторювати їх можна у своєму темпі.

## Дані

Папка **data** містить прогрес, резервну копію та навчальні репозиторії. Після перезапуску тренажер відкриває попередню вправу з робочими файлами, staging та незавершеним merge або rebase. «Скинути вправу» відкриває чисту копію вибраного сценарію. Позначка про проходження зберігається.

Сервер приймає визначені у довіднику форми Git-команд у навчальних папках. Уроки з віддаленим репозиторієм використовують локальний origin та окремий клон колеги. Адреса з вікна запуску відкриває поточний локальний сеанс.

Recall підключається до цього самого локального сервера та збереження. Якщо окреме вікно Git Tutor було запущено до оновлення сервера, заверши його через Ctrl+C перед першим відкриттям у Recall.

Для перевірки всього курсу виконай **npm test**.
